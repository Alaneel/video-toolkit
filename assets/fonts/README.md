# Desktop font

DM Sans is included under the SIL Open Font License 1.1 in `OFL.txt`.

Source: [Google Fonts DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), `DMSans[opsz,wght].ttf`, retrieved 2026-10-18, stored unchanged as `DM-Sans.ttf`. The desktop uses its default regular face for body text and egui's font fallbacks.

`DM-Sans-SemiBold.ttf` (wght 600, opsz 14) and `DM-Sans-Bold.ttf` (wght 700, opsz 32) are static instances derived from that file with `fonttools varLib.instancer`, used for labels and headings. Modified versions remain under the OFL; the reserved font name rules in `OFL.txt` apply.

All faces are embedded locally and make no font network requests.
