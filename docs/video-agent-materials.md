# Video Agent 公开素材与验证说明

首个公开演示使用 Blender Foundation 的《Big Buck Bunny》动画短片。它包含真实编码的连续画面与音轨，适合检查抽帧、选片、人工修改和导出，但不是实拍视频，不能据此宣称系统已验证海景、城市夜景或通用视频理解能力。

## 素材许可与来源

素材来自 [Blender 官方下载目录](https://download.blender.org/peach/bigbuckbunny_movies/)，[官方许可说明](https://peach.blender.org/about/)允许按 CC BY 3.0 复用片段。共享剪辑、截图或演示时，应保留署名、[许可链接](https://creativecommons.org/licenses/by/3.0/)和修改说明：

> (c) copyright 2008, Blender Foundation / www.bigbuckbunny.org

剪段经过裁切、偶数尺寸补边和重新编码，基线还进行了顺序拼接；这些改动不能被描述为原版电影或 Blender 背书。完整电影再分发应保留完整片尾。电影许可不覆盖 Blender 等标志和商标，仓库的 MIT 许可也不替代素材许可。不单独下载或分发原声专辑。

下载脚本核对压缩包和原片两个固定 SHA256。原片为 596.462 秒、H.264 640×359、24 fps，含 AAC 双声道音轨。原片只读；所有派生文件写入另选目录，已有内容不匹配时直接失败，不能静默覆盖。

## 开发样本与冻结任务

开发片取原片 30–105 秒；冻结测试片分别取 180–255 秒、330–405 秒，时间区间不重叠。准备脚本默认仅生成开发片。运行冻结测试前固定代码提交、提示词版本和模型配置，再显式打开 heldout 开关；不要把冻结片拿来调界面或调提示词。冻结任务若用于修复，应退出后续泛化评估并补充新版本任务。

开发任务包含兔子与树林的正向选择，以及海景和城市夜景的负向请求。后者用于保留拒绝、证据不足和错误替代的失败案例，不预先填入“模型正确拒绝”的结论。冻结任务分别关注小型动物、天空与林地的视觉对照；不预设素材一定包含完整所需内容，允许少选或拒绝。

固定间隔基线在四个等长区间中央各取 5 秒，共 20 秒，生成真实可解码视频和原片时间映射。它不使用模型或语义，是比较对象，不是视觉模型演示。详细复现命令、输入指纹、评估字段和评分规则见 [评估说明](../evals/video-agent/README.md)。

## 验证结论的边界

流程测试、媒体测试和语义评价分别记账。流程测试证明参数校验、确认版本和恢复等状态行为；媒体测试证明某个具体文件的时长、流和可解码性；只有人在固定任务上复看片段及实际采样证据，才可评价相关性、遗漏和理由忠实度。人工修改后的结果不能当成模型初稿成绩。

2026-10-18 用户已在本机配置凭据；首次真实调用在明确同意后发送公开开发素材的12张样本，模型提出18.75秒单段，超过15秒上限，被确定性校验拒绝，记录未删除。真实模型驱动导出与人工语义评分仍待验证，见 [当前状态](../evals/video-agent/results/status.json)。导出成功、基线视频或模拟提供者测试不能抵消这些缺项。只对获准的公开素材发送采样 JPEG、时间码、任务意图与必要元数据，原视频不上传。

三分钟演示应依次展示用户意图、真实模型观察与选择、人工删改、针对新版本的确认、处理中断与恢复、最终播放与结果检查。现有演示提纲不是已经录制的视频；发布前应检查截图与录屏不含凭据、私人素材或本地运行记录。所有线上 push、release、仓库名和 Profile 更新留在最终发布清单，本轮材料脚本不进行这些操作。
